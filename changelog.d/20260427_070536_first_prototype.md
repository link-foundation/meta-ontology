### Added
- First prototype (MVP) of the meta-ontology project (resolves #1).
- Seed data: 65 NSM semantic primes, ~25 self-referential lino primes,
  cross-ontology mappings to Schema.org / OWL / SUMO / Wikidata, English
  exponents (full) plus Spanish and Russian (full).
- `meta-ontology` library with `Ontology`, `Concept`, `Definition`, and
  `Mapping` types, plus a loader that parses `.lino` files and a word
  scanner that backs the CI coverage check.
- `meta-ontology` CLI binary with `list`, `show`, `check-words`, and
  `langs` subcommands.
- `REQUIREMENTS.md`, `ROADMAP.md`, and `docs/plan/` with detailed,
  per-slice implementation instructions.
- Deep case-study analysis in `docs/case-studies/issue-1/` (research
  notes on NSM, popular world ontologies, and the link-foundation
  crates).
- CI workflow step `Ontology Word Coverage` that fails the build if
  `README.md` contains a word that is not in the ontology and not on
  the allow-list.

### Changed
- Renamed the package from `example-sum-package-name` to `meta-ontology`
  and rewrote the README to describe the project.

### Removed
- Template-only `sum` example and its tests.
